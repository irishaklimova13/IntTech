# RTS Game — Команда 4

Учебный командный проект по дисциплине «Современные интернет-технологии».

Проект представляет собой браузерную стратегическую игру в реальном времени (RTS). Игровое поле, объекты и действия пользователя реализованы на Vue 3.

## Технологии

- Vue 3
- Vuex 4
- TypeScript
- Vite

## Запуск проекта

Требуется Node.js версии 20.19+ или 22.12+.

Откройте терминал в корне репозитория и выполните:

```bash
cd vue
npm install
npm run dev
```

Vite выведет локальный адрес, по которому доступна игра.

## Проверка проекта

Сборка:

```bash
npm run build
```

Автоматические тесты игровой логики:

```bash
npm test
```

## Основные игровые механики

В проекте реализованы игровое поле с разными типами местности, перемещение и выбор юнитов, поиск маршрутов, строительство зданий, характеристики и здоровье объектов, боевые действия, а также водный транспорт.

Подробности реализации находятся в [vue/IMPLEMENTATION.md](vue/IMPLEMENTATION.md).
